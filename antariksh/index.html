About this project

Mini-project for Multimedia Systems Practical (3IBCA504). It combines the main multimedia elements:

  • Text — planet facts and quiz
  • Graphics — planets drawn with SVG and Canvas
  • Animation — real-time orbits with requestAnimationFrame
  • Audio — ambient sound generated live with the Web Audio API
  • Video — HTML5 video player
  • Interactivity — click, slider, quiz, theme switch

Made by Kanak Prabhakar · BCA, AISECT University, Hazaribagh
